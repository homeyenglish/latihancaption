Konfigurasi Webhook Google Spreadsheet

Tempelkan URL Web App Google Apps Script Anda (berakhiran /exec). Semua data pengerjaan ujian siswa akan dikirimkan otomatis ke spreadsheet tujuan:

Skrip Google Apps Script (Apps Script Editor): Deploy as Web App 
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000); // Menghindari tabrakan saat banyak siswa submit bersamaan

  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Parsing data baik berupa JSON string maupun Form URL Encoded
    var data;
    if (e && e.postData && e.postData.contents) {
      try {
        data = JSON.parse(e.postData.contents);
      } catch (err) {
        data = e.parameter;
      }
    } else if (e && e.parameter) {
      data = e.parameter;
    } else {
      data = {
        name: "Test Manual",
        studentClass: "XI A",
        score: 100,
        correctCount: 50,
        wrongCount: 0,
        duration: "0m 0s"
      };
    }

    // Menyimpan baris: [Tanggal/Waktu, Nama, Kelas, Skor, Benar, Salah, Durasi]
    sheet.appendRow([
      new Date(), 
      data.name, 
      data.studentClass, 
      data.score, 
      data.correctCount, 
      data.wrongCount, 
      data.duration
    ]);

    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}

// Fungsi tes manual untuk memastikan sheet bisa ditulisi tanpa error:
function testSheet() {
  doPost(null);
}
*Catatan Penting: Jangan tekan tombol ▶️ Run pada doPost di Apps Script (karena pasti menghasilkan error undefined postData). Untuk tes manual dari editor, pilih dan jalankan fungsi testSheet.
*Saat Deploy > New deployment: pilih Web app, atur Execute as: Me, dan Who has access: Anyone.

Rangkuman Materi: Caption Text (Grade 11)

1. Definisi & Fungsi Sosial

Caption text adalah teks singkat yang menyertai gambar, foto, grafik, tabel, atau video guna memberikan konteks, identitas, waktu, dan keterangan pelengkap yang tidak dapat langsung diketahui secara utuh dari visual saja.

2. Jenis-Jenis Caption Utama:

  • Identification Bar: Menyebutkan siapa subjek dalam gambar (*Who*).
  • Cutline: Menyebutkan siapa di dalam foto dan apa aksinya (*Who & What*).
  • Summary: Memuat unsur lengkap 5W+1H (*Who, What, Where, When, Why, How*).
  • Expanded: Format paling lengkap: 5W+1H disertai kalimat kedua berisikan latar belakang atau kutipan narasumber.
  • Quote: Kutipan perkataan narasumber atau tokoh yang relevan dengan pesan gambar.
  • Group Identification: Mengidentifikasi nama-nama beberapa orang dalam gambar dengan orientasi spasial (*misal: left to right*).

3. Kaidah Kebahasaan (Language Features):

  • Kalimat pembuka (*lead*) memakai Simple Present Tense agar terkesan terjadi saat visual disaksikan.
  • Latar belakang atau riwayat kejadian sebelumnya diungkapkan dalam Simple Past Tense.
  • Memuat Prepositional Phrases keterangan tempat dan waktu secara spesifik.
  • Memuat Photo Credit / Byline di akhir caption.
